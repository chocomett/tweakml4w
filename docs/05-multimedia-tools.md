# 05. Multimedia Tools

This guide installs the multimedia applications I use on every fresh installation.

---

# Install

```bash
sudo pacman -S \
gwenview \
mpv \
obs-studio
```

---

# Applications

| Application | Purpose |
| ------------ | ------- |
| **Gwenview** | Image Viewer |
| **mpv** | Video Player |
| **OBS Studio** | Screen Recording & Streaming |
